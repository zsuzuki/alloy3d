# 不透明シーンの参照とソフトパーティクル

`RenderOptions{4, true, true}` はHDRに加え、不透明部分の色・線形深度を保存する。通常の描画は従来の単一パスを使い、この設定を指定した場合だけ、不透明・MASK → スナップショット → 深度順のBLEND → ポスト処理 → 2Dの順になる。

`SetModelSoftParticles3D(distance)` は、以後のモデルのBLEND／配置色によるフェードに適用する。地形などとの距離が `distance` 未満になると、アルファを滑らかに落とす。単位はワールド座標、0で無効、有効範囲0〜100。非対応コンテキストはfalseを返す。OPAQUEとMASKには適用しない。

forestは水滴に0.045を使用し、Cキーで切り替える。透明物同士はこの深度に入らない。4×MSAAでは最も近い深度サンプルを採用するので、輪郭で保守的にフェードする。クリア深度は遠方として扱う。

色・深度の追加メモリは `RenderMemoryStats.postProcessBytes` に含む。各フレームページに専用の深度、解決済み色、R32Float深度を確保し、リサイズ／`ReleaseUnusedRenderMemory` 後のページ再利用時に再作成する。MSAA色と深度は半透明パスまで保持する。3Dの線・面は不透明側、3Dテキストは半透明側に描く。

`scene_depth_regression` は1×/4×MSAAの無効時互換性、数値的なフェード量、空背景、非対象の不透明材質、カリングと透明バッチのGPUバッファ共存、メモリ再確保を検証する。
