# 深度と影を使う光芒

`PostProcessing3D.volumetric` に `VolumetricLight3D` を指定する。既定の `strength=0` は無効で、光芒用テクスチャや計算パイプラインを作成しない。有効化には `RenderOptions.hdr` と `sceneEffects` が必要。

カメラから不透明深度までの経路を半解像度で積分し、方向光の影マップで各地点を遮蔽する。高度に応じた指数密度、Beer–Lambert減衰、方向依存の散乱を使う。3D描画後に加算し、トーンマップの前に合成する。2Dには影響しない。

- `strength`: 0〜4。光色は現在の方向光と拡散強度を引き継ぐ。
- `density`: 0〜1、ワールド距離あたりの密度。
- `baseHeight` と `falloff` (0〜10): ワールドYに対する密度分布。
- `maxDistance`: (0,1000]。`steps`: 8〜64、既定32。
- `anisotropy`: -0.9〜0.9、正で前方散乱を強くする。

深度に応じて補間するため、単純な線形拡大より岩・幹の輪郭からの漏れを抑えられる。固定サンプルなので時間的な履歴・残像はないが、薄い遮蔽物や細かい影は見落とし得る。透明物は遮蔽深度に含まれない。影マップ外は照明ありとして扱うため、`DirectionalShadow3D.bounds` は光芒の範囲も考慮する。背景の減衰は既存の霧機能で調整する簡易単一散乱であり、多重散乱や雲シミュレーションではない。ブルームの抽出は光芒を含まない元のHDRシーンから行う。

forestは既定で有効。Bは光芒と光の粒子全体、Yはこの方式と従来の板状の光を切り替える。高度霧とは独立に調整できる。

`volumetric_regression` は1×/4×MSAA、奇数サイズ、解析的な積分値、不透明面による終端、影だけの遮蔽物、アルファの保存、無効時復元、メモリ解放を検証する。
