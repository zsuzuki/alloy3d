# 画面サイズLODとディザ切替

`ProjectedHeight3D(camera, center, radius)` は球の直径を画面の高さに対する比率へ換算します。
透視投影では中心深度を使う近似です。目の平面に触れる球は最大詳細を選びます。
半径にはモデル配置のスケールを含めます。平行投影では距離に依存しません。
`SelectLod3D(size, thresholds, band)` に降順の閾値を渡すと、隣接する詳細レベルと混合率を返します。
閾値の前後10%が標準の切替区間です。履歴に依存せず、同じカメラへ戻ると同じ結果になります。

`ModelInstance.coverage` または `SetModelCoverage3D({start,end})` で描画するディザ区間を指定します。
高詳細を `{0,1-weight}`、低詳細を `{1-weight,1}` にすると8×8の固定パターンを補完します。
通常値は `{0,1}` です。配置アルファは1を保ち、深度書き込み・インスタンス描画を維持します。
影にも同じ規則を適用します。色と影ではそれぞれの画素座標を使います。
カスタムシェーダー・透明モデル・MSAAにも対応します。

forestの樹冠は3段階LODで使用します。ディザはTAAを使わないため、近くでは粒が見えます。
輪郭の異なるモデル間では同一メッシュほど完全には補完しません。ビルボードの8方向選択は従来どおりです。
`lod_regression` では画面サイズ、切替率、単体・一括・半透明バッチ、1/4サンプルでの補完を検証します。
