# 描画品質の設定

## MSAA

起動時の `ApplicationLoop::GetRenderOptions()` でサンプル数を指定します。

```cpp
alloy3d::RenderOptions GetRenderOptions() const override { return {4}; }
```

初期値は1（MSAAなし）です。1・2・4・8を受け付け、端末が対応しない場合は
指定値以下で対応する最大値へ下げます。それ以外の指定は例外になります。
起動後の変更は行わず、3D・2Dのパイプラインと描画先を同じサンプル数で作成します。
モデル、基本図形、文字、カスタムモデルシェーダーが対象で、影用マップは単一サンプルのままです。
利用側もライブラリと一緒に再ビルドしてください。

MSAAは幾何の輪郭を滑らかにします。MASK画像内部の切り抜きや、材質の模様・反射のちらつきは
別の問題で、Alpha-to-Coverageやテクスチャフィルタとは区別します。
サンプル数を増やすと描画先メモリとGPU処理が増えるため、端末と解像度ごとに確認してください。

forestは4サンプルを要求します。比較用プローブは従来どおり1サンプルが既定で、
`ALLOY3D_FOREST_SAMPLES=4` を指定すると4サンプルで描画します。
`msaa_regression` は解決後の輪郭の中間色と、通常・カスタム・インスタンス・透明・影の一致を検証します。
