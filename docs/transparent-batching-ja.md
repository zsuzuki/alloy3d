# 半透明の一括描画

`ctx.SetTransparentBatching3D(true)` で、奥から手前へ並べた半透明パーツのうち、同じパーツ・
シェーダー・設定が連続する範囲をインスタンス描画にまとめます。初期値はfalseで従来の個別描画です。
描画時のフレーム全体に適用する設定です。DrawModel3DとDrawModelInstances3Dの双方が対象です。

配置・色・アルファはインスタンスごとに保持します。他のパーツや異なるシェーダー設定が間に入ると
そこで分割するため、既存の安定ソート順を維持します。深度書き込みは引き続き無効です。
複数パーツの透明モデルも全体でソートした後に連続部分だけをまとめます。
半透明を全部1回で描く機能ではなく、交差する面やパーツ内部の合成順の制約も従来どおりです。

CPUのモデル登録とソートは残りますが、GPUへの描画コマンドを削減できます。
追加の描画パスはなく、既存の3フレーム分のインスタンスバッファを再利用します。
各フレームの透明パーツ数に応じた領域が増え、ReleaseUnusedMemoryで安全なフレームから解放できます。
カスタムシェーダーは通常・透明・MSAA被覆の単体／インスタンス用6パイプラインを作成します。

forestはこの最適化を有効にします。プローブでは同じ時刻の無効時とピクセル完全一致を確認し、
両方の描画回数を表示します。`transparent_batch_regression` は間に別のモデルが入る場合、
複数パーツ、異なる設定、反転・アニメーション・影とバッファ拡張を検証します。
