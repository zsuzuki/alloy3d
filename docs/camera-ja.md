# カメラとモデルの全体表示

`CameraData` は小さな行列・設定クラスです。周回操作や追従制御はアプリ側で組み立てます。
今回、透視投影の奥行きをMetalの `[0, 1]` に修正し、正射影と全体表示を追加しました。

## 投影と視点

```cpp
#include <alloy3d/camera.h>

auto &camera = ctx.GetCamera();
camera.buildPerspective(0.785398163f, aspect, 0.1f, 100.0f); // 垂直画角45度、単位はラジアン
camera.buildModelView({8, 5, 12}, {0, 1, 0}, {0, 1, 0});
// 正射影へ切り替える場合。高さ10、幅10 * aspectの範囲。
camera.buildOrthographic(10.0f, aspect, 0.1f, 100.0f);
```

- ビュー空間は右手系で、前方は `-Z`。nearは深度0、farは深度1に対応します。
- 透視投影は `0 < fovy < π`、`aspect > 0`、`0 < near < far`。
- 正射影は `height > 0`、`aspect > 0`、`0 <= near < far`。
- 入力は有限値で、生成される行列もfloatで表現できる必要があります。
  不正な値は `std::invalid_argument` となり、変更前のカメラを保持します。
- eyeとlookが同じ位置の場合はエラーです。upがゼロ、または視線とほぼ平行な場合は、
  視線に直交する安定した軸で補います。`getUpDirection()` は補正後の上方向です。

`setAspectRatio(aspect)` は投影方式・画角または高さ・near/farを保って幅を更新します。
アプリケーションホストもリサイズ時にこの処理を使うため、利用側の設定を上書きしません。
幅または高さが0の通知では、ホストは直前のaspectを保持します。

単体で作った `CameraData` の投影・ビュー行列は従来どおり単位行列で、モードは
`ProjectionMode::Identity` です。メタデータは画角π/4、aspect 1、near 0.1、far 1000で初期化します。
ホストは起動時に一度だけ透視投影を設定します。`getProjectionMode()`、`getFieldOfView()`、
`getOrthographicHeight()`、`getNearPlane()`、`getFarPlane()`、`getAspect()` で設定を取得できます。

## モデルを画面に収める

```cpp
alloy3d::Bounds3D bounds;
if (model->GetBounds(bounds))
{
  // モデルに配置変換がある場合は、同じアフィン行列でワールド座標へ変換する。
  auto worldBounds = bounds.transformed(modelToWorld);
  ctx.GetCamera().fitBounds(worldBounds, 1.1f);
}
```

`Bounds3D` は軸に平行な境界箱で、`min` と `max` を持ちます。初期状態は空です。
`include(point)` / `include(bounds)` で点・境界を追加し、`isValid()` で有効性を調べます。
空・無効な境界をincludeしても変化しません。非有限の点はエラーです。
`transformed(matrix)` は8隅を変換した境界を返すため、回転や負のスケールにも対応します。
有限のアフィン行列のみ受け付け、射影行列はエラーになります。

`Model::GetBounds` は、ノード変換と**現在のアニメーション姿勢**を反映したモデル座標の境界を返します。
`DrawModel3D` のposition/rotation/scaleや、インスタンスごとの配置は含みません。
取得できないモデルではfalseとなり、渡した出力値は保持します。
同じ姿勢を描くインスタンスは一度取得した境界に各配置を適用し、`include` でまとめられます。

境界の取得では、読み込み後に変化しない共有頂点・インデックスバッファをCPUから参照し、
現在のジョイント行列で計算します。頂点配列の複製やGPUからの読み戻し・完了待ちはありませんが、
描画インデックス数に比例したCPU計算が発生します。ロード時、モデル切り替え時、全体表示操作時などに
呼んでください。アニメーション更新と同じスレッドで使います。

`fitBounds` は境界箱を包む球から保守的に距離を求めます。
視線方向と投影方式を保ち、注視点・視点・near/far・正射影の高さを更新します。
Identityから呼ぶ場合は透視投影を選びます。`padding` は1以上、既定値は1.1です。
一点だけの境界も扱い、その場合は半径0.001を最低値として使います。
空の境界、不正なpadding、floatで表現できない結果は変更前のカメラを保持してエラーになります。

全アニメーション期間の最大範囲ではなく、呼び出した時点の形を収めます。
後のアニメーションや移動で範囲が広がった場合には、必要に応じて再度呼び出します。

## ビューワー

- **O**: 透視投影と正射影を切り替え。注視点での見かけの大きさを維持します。
- **F**: 表示中のモデルの現在姿勢と配置から、全体が入るように調整します。
- **R**: 初期の透視投影・視点・クリップ範囲に戻します。
- 矢印キー / 右スティック: 現在の注視点を軸に周回します。

Fは通常の展示とインスタンスデモの両方に対応します。グリッドと文字は境界計算に含めません。
境界はF操作時だけ計算し、通常の各フレームでは取得しません。

## 検証と互換性

`camera_cpu` は投影の端点、パラメータ検証、退化したup、リサイズ時の設定保持、
境界変換、縦長・横長での全体表示を検証します。
`camera_gpu` はMetal上の近遠クリッピング、正射影の奥行きによらない大きさ、
静的・スキニングモデルの境界と全体表示、共有モデルの姿勢の独立性を検証します。
既存の描画・アニメーション・メモリ・インスタンス回帰テストも併用します。
既存のテストGLBを利用するため、追加のモデルファイルは不要です。

従来の透視投影はOpenGLの深度範囲 `[-1, 1]` でした。修正後は指定したnearから表示されるため、
以前の実効クリップ位置に合わせて値を調整していたアプリでは見え方が変わります。
角度は以前からラジアンを想定していましたが、今回から範囲外の値を明示的に拒否します。
公開クラスのレイアウト・仮想関数が増えるため、利用側も再ビルドしてください。
