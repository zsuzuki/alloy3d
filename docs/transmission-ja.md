# 薄い面の透過光

`ctx.SetModelTransmission3D({.45f, {.75f, 1.f, .4f}})` で葉などの逆光を補えます。
初期strengthは0（無効）。strengthと線形RGBのcolorは有限の0〜1です。
不正値は例外になり以前の設定を保ちます。各描画とインスタンス群の登録時に保存します。

面の裏側から当たる平行光を使い、光が視点へ向かうと強くなる近似です。
baseColor、光源色・強度、指定色、シャドウマップの可視率を掛けます。
表側からの光には加算せず、Unlitには適用しません。新しい画像や描画パスは不要です。
アルファ、物体の厚み、背景の屈折を変える機能ではありません。
`ModelSurface::transmissionColor` はこの加算分で、`litColor`にも含まれます。

forestでは草・シダ・3Dの葉群に使い、`T`で切り替えます。
遠景樹冠の画像は焼き込み時の照明のままです。
