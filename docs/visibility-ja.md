# 可視判定

`SetFrustumCulling3D(true)` はモデルのカラー描画を視錐台で間引きます。初期値はfalseです。
`Frustum3D(camera).intersects(bounds, modelToWorld)` はアプリケーションでも使える判定です。
Metalの深度範囲0〜1、透視／平行投影、負スケール、境界への接触に対応します。

モデルの現在姿勢に対する保守的な境界を再利用します。スキニング後の頂点全走査はしません。
不明な境界は残し、影パスの配置は減らしません。画面外の木が落とす影も保持します。
インスタンスはカラー描画用に可視の配置だけを詰め、元の順番を保ちます。
3フレーム分の既存インスタンスバッファを使用し、`ReleaseUnusedMemory()` で縮小できます。

forestは有効にしています。`visibility_regression` は境界・回転カメラ・各アルファモード・
アニメーション・負スケール・個別／一括描画で、OFFとの画素一致と影の描画回数を確認します。
