# モデルテクスチャのミップマップ

GLBの埋め込みベースカラー画像から、読み込み時にミップマップを自動生成します。
APIの追加呼び出しは不要です。遠景や小さく表示したモデルの模様のちらつきを抑えます。
拡大時は従来どおり元画像を線形補間します。

## 実装と負荷

- MetalKitで全段を確保し、2段以上ある場合だけGPUのblitで生成します。
  1×1画像は1段のままです。縦横が2の累乗でない画像にも対応します。
- 読み込み関数内で生成完了を待つため、描画側が別のコマンドキューでも未初期化の段を読みません。
  毎フレームの生成、追加の描画パスはありません。
- モデルの通常描画・インスタンス描画・カスタムシェーダーでトライリニア補間を使います。
  MASKの影描画も同じサンプラー設定です。
- 色画像はsRGB形式を維持し、ミップ生成・補間は線形RGBで行います。
  `CreateModelInstance` で複製したモデルは、元画像とミップマップを共有します。
- メモリは大きな正方形画像なら約33%増加します。縦横比によって増加率は異なります。
  ロード時の生成・同期と、描画時の隣接段のサンプリングにはコストがあります。

2D画像・文字、3D文字のテクスチャ、シャドウマップ自体は変更していません。
異方性フィルタリング、glTF sampler設定の読み取り、ミップレベルの手動指定は今回の対象外です。
モデルは固定のrepeat・linear・mip linear設定です。ライブラリと `shaders.metallib` を
一緒に更新してください。カスタムシェーダーの公開入力は変更していません。

## 切り抜き素材の制約

アルファも通常の平均化で縮小し、その結果に既存の `alphaCutoff` を適用します。
葉や金網など細い部分は、遠景で薄くなったり消えたりする場合があります。
逆に不透明部分の割合が大きい模様では、小さい穴が埋まる場合があります。
アルファの被覆率を維持する補正は行いません。

色と影は同じ補間方式を使いますが、カメラと光源では投影や解像度が異なるため、
選ばれるミップレベルと切り抜き形状が完全に一致するわけではありません。

## 検証

`mipmap_regression` は全段の生成完了、sRGBの線形平均、拡大・縮小描画、1×1、
非2冪画像、モデル共有、カスタムシェーダー、インスタンス描画、MASKとその影を検証します。
テスト画像は `tools/generate_mipmap_fixtures.py` で生成した、このリポジトリ専用の画像です。

```sh
python3 tools/generate_mipmap_fixtures.py --check
cmake --build build -j 8
ctest --test-dir build --output-on-failure
```

2026-09-11、Apple M3 Ultra・Releaseで、変更前 `aebe30b` と比較しました。
1024×1024の1ピクセル市松模様を約168ピクセル幅に縮小し、12回微小移動した結果です。

| 指標（8bit線形RGB） | 変更前 | ミップマップあり |
|---|---:|---:|
| 平均色からのRMS偏差 | 41.915 | 0.500 |
| 微小移動時の画素差の平均 | 36.781 | 0.000 |

同じ画像を拡大した比較では、画素ハッシュ `4c35412aa13581d1` が一致しました。
これは市松模様による検証結果で、任意のアセットでちらつきがゼロになることは保証しません。

既存の1536×1536・144個のテクスチャ付きモデル＋床と球のシーンでは、
フォグ・環境光OFF時のGPU中央値は **0.1055 → 0.1070 ms** でした。
最初の20フレームを除いた80フレーム、影OFF、MSAAなし、Metal API Validationなしの結果です。
モデル描画は1回のインスタンス描画を維持しています。この条件では高速化は確認していません。
読み込み時間とメモリ増加はこのGPU描画時間に含まれません。

Metal API Validationを有効にした回帰テストは17件すべて成功しました。
1×1画像ではMetalKitの `GenerateMipmaps` オプションが無効な生成命令を発行する挙動を
確認したため、段数確認付きの明示生成にしています。

参考: Appleの[ミップ生成](https://developer.apple.com/documentation/metal/generating-mipmap-data)、
[ミップマップ用サンプラー](https://developer.apple.com/documentation/metal/adding-mipmap-filtering-to-samplers)。
