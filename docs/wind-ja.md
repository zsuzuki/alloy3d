# モデルの風変形

`SetModelWind3D(wind)` は根元を固定し、上に行くほど二次曲線で曲がる風を設定します。
初期値の `strength=0` は無効です。時間・方向・振幅・基準高さ・先端高さ・周波数を設定できます。
設定は描画要求にコピーします。インスタンスのワールド配置から位相を作り、同位置の枝と葉は同じ動きをします。

スキニング後のモデル座標に適用します。`direction` はモデルXZ軸、長さは正規化されます。
変形する部分は適切に細分化したメッシュを使います。粗い三角形では頂点間が直線補間されます。
法線は変形の逆転置、タンジェントは順変換で補正します。陰影・法線マップ・カスタムシェーダーにも反映されます。
カラー／影パスで同じ変形を使い、可視判定の境界も最大変位まで広げます。
アプリが同じ時間を渡す間は色も影も停止します。汎用の任意頂点シェーダーではなく、軽量な専用変形です。

forestは草・シダ・樹冠・葉・遠景カードに使用します。以前のCPUによる全体回転を置き換えました。
`V` で切り替えます。`wind_regression` は根元固定、法線、姿勢・配置、個別／一括、影、時間再現性、入力検証を確認します。
