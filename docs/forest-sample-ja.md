# 雨上がりの森林サンプル

`alloy3d_forest` は、屋久島のような鬱蒼とした森林の雰囲気を目指す独立したサンプルです。
草・シダ・葉の揺れ、木漏れ日、苔の緑、湿った空気の奥行きに、再帰生成した枝ぶりと密度のある樹冠を組み合わせています。
既存の viewer とライブラリの描画設定は変えません。

## ビルドと起動

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DALLOY3D_BUILD_FOREST=ON
cmake --build build --target alloy3d_forest -j 8
open build/alloy3d_forest.app
```

`ALLOY3D_BUILD_FOREST` の初期値は `ALLOY3D_BUILD_VIEWER` に従います。
ライブラリだけをビルドする既存の構成では OFF になり、森林だけを ON にすることもできます。
設定済みのビルドディレクトリでは CMake のキャッシュ値が維持されます。

## 操作

| キー | 操作 |
| --- | --- |
| 矢印 | 左右・上下を見回す |
| W / S | 小道に沿って少し前進・後退 |
| R | 初期視点へ戻る |
| V | 草・シダ・葉の風揺れ |
| G | 距離フォグ |
| B | 光筋・林床の明るい斑点・浮遊粒子 |
| H | 樹木と植生のシャドウマップ |
| F | 小川の流れと水滴を停止・再開 |
| I | 遠景の樹冠ビルボードを切替 |
| P | 小川の水滴を表示・非表示 |
| Space | アニメーションを一時停止・再開 |
| Tab | タイトルと操作案内の表示・非表示 |
| Cmd+Q | 終了 |

風を OFF にすると植生は静止姿勢に戻ります。Space は、その時点の揺れ・光・粒子を止めます。
カメラ操作は一時停止中も可能です。比較しやすいように、配置は毎回同じです。

## 描画の構成

- 地面には湿った土と落ち葉、幹・根・枝には縦方向の樹皮、岩には苔と石肌のテクスチャ。
- 地面は実寸 1.6m ごとの UV、幹は連続した円周 UV、岩は経緯方向の UV で配置。
- 地面・幹・岩の法線を滑らかにつなぎ、岩は輪郭が角張りすぎないよう分割数を増加。
- 3 枚のベースカラー画像は GLB に内包し、sRGB 読み込みとミップマップで距離によるちらつきを抑える。
- 草、シダ、葉群は不透明の両面メッシュを共有し、インスタンス描画。
- 草・シダは根元、樹冠の枝と葉は共通の支点を中心に、場所ごとに位相を変えて揺らす。
- 晴れ間の淡い青空に合わせた薄い距離フォグ、空と地面で色を分けた環境光、暖かく強い平行光源。
- 2048×2048 のシャドウマップで葉・枝から林床へ影を落とす。
- 葉の透過光に似た明るさ、林床のゆっくり動く明暗を、サンプル専用のモデルシェーダーで補う。
- 6 本の光筋は、端と上下でアルファを滑らかに落とした半透明の面。
- 苔の岩や林床には控えめなハイライト。光筋の周囲に小さな浮遊粒子。

光筋はボリューム散乱の計算ではなく、特定の視点範囲で雰囲気を作る近似です。
物体による通常の深度遮蔽はありますが、光路の途中にある枝によって光筋自体を遮断する計算はしません。
林床の補助的な明暗も、葉の位置から直接投影するものではありません。
木の風は上部の幹・枝・葉を一緒に回転する近似で、葉一枚ずつの変形ではありません。
テクスチャはベースカラーのみです。凹凸の法線マップ、苔の立体的な毛並み、雨滴、
水たまりの反射、精密な樹種の再現はまだ含みません。

小道の右手に幅約1.5〜2.2mの小川を配置しています。川底と岸を地形に作り、植生は岸へ寄せています。
水面の高さは奥から手前へ単調に下がり、UVも同じ向きに進みます。
760三角形の静的な帯メッシュに、画像生成した水面テクスチャを約0.31m/秒で流しています。
テクスチャの色を水面に使い、明暗の微分と小さな周期波から細波の陰影を補います。
細波は頂点変形ではなく、UVから計算した傾きによって反射光を揺らします。
画像内の反射光と空の反射色は近似で、実際の木々を映す反射・屈折や流体シミュレーションは行いません。
`F` は水の時刻だけを固定し、再開時はその位置から続きます。`Space` は森林全体を止めます。

岸と水中の石の下流側から、大量の水滴が低く跳ねます。8,000 個の固定発生枠のうち、
80 個を小川全体に残し、追加の7,920 個はカメラ付近へ配分します。岸の追加枠は視点に合わせて
近くから中距離の水際に配置し、石の追加枠は石の下流側を維持します。水平距離10m以内は濃く、
10〜20mで滑らかに薄くなり、それより遠くは背景の少量だけになります。
発生枠の間隔を広げ、同じ総数を従来の約2倍の範囲に分散しています。
見えている水滴の発生位置は地面に固定し、カメラ移動時の横滑りを防ぎます。
400 枠版に対して発生枠を20倍にし、通常の77種類は上向きの初速を36%抑えています。
通常は約 0.15〜0.24 秒の短い放物線を描き、水面から約 4〜8cmまで跳ねて消えます。
残り3種類だけ、左右の岸と石の下流側で約12・14・16cmまで高く跳ねます（約0.30〜0.35秒）。
下流への速度は約 0.32〜0.60m/秒で、川の曲がりに沿いながら岸から少し内側へ動きます。
水滴は 32 三角形の小さな半透明メッシュを共有し、上部の淡い光と縦方向の伸びで水らしさを補います。
粒の大きさは従来の75%に縮め、白い飛沫と水面の中間を狙った淡い青緑色にしています。
高さ・速度・周期などは80種類の発生設定ごとに固定シードの乱数で決め、位置と位相をずらして
繰り返します。跳ねるたびに再抽選する方式ではないため、同じ時刻の動きは再現できます。
発生位置を少しずつ散らして、多数の粒が同じ軌道に重なって白い線になるのを抑えます。
`P` で表示を切り替え、`F` と `Space` で流れと一緒に停止・再開できます。
飛沫の動きはサンプル内の時刻計算で、流体・物体衝突のシミュレーションは行いません。

小さな流れにはUVスクロールと細波の陰影を優先し、輪郭が上下する波や滝が必要になった段階で
頂点変形を加える構成です。幾何の波と細波を分ける考え方は
[NVIDIA GPU Gemsの水面表現](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-1-effective-water-simulation-physical-models)も参照しています。

## 再帰的な樹木生成

`tools/generate_forest_assets.py` の `forest_tree()` は、大枝から末端の小枝まで 4 段階で分岐します。
規則を再帰的に適用しながら、枝の長さ・分岐位置・曲率・分岐面の向きに固定シードのばらつきを加えます。
形式的な L-system インタープリターや光の成長シミュレーターではありません。
生成はオフラインで完了し、実行中に樹木形状を計算し直すことはありません。

- 樹高・枝張り・幹の傾きが異なる 3 種類を混ぜて配置。枝張りを広げ、木の本数と葉の数を増やさず頭上を覆う範囲を増加。
- 幹は 24 分割の断面、根と枝は曲線に沿った断面で作り、先端に向けて細くする。
- 小枝の節から葉を立体的に配置。近景の葉は曲面状の 8 三角形で輪郭と中央の折れを表す。
- 1 本あたり約 970〜990 本の枝、約 1.5 万枚の葉、約 19 万三角形。
- 地上 4m（配置スケール適用前）を境に下部の幹・根を固定し、上部の木部と葉は共通変換で揺らす。
- カメラから幹までの水平距離が 24m を超えると、同じ枝の骨格を基にした約 4.8 万三角形の中景モデルへ切り替える。
  中景は枝の断面・長手方向の分割を減らし、葉は半数を少し広げた 4 三角形にする。
- 38m より遠い樹冠は、同じ 3D モデルを 8 方向から描いた 768×768 の画像を持つ 2 三角形のビルボードにする。
  幹と根は 3D のまま残す。画像は視点方向に合わせて選び、面はカメラを向く。
  MASK 材質なので葉の隙間は抜け、ミップマップも使用する。`I` で中景モデルとの比較が可能。

遠景の光は画像に焼き込み、霧は描画時に適用します。視点の上下による見え方の変化、
ビューや詳細度のクロスフェードは未対応です。ビルボードが落とす影も切り抜き面による近似です。

枝と葉の素材は共有したままインスタンス描画します。距離による選択も森林サンプル側の処理です。
既存の樹木の水平位置、手前の林床・小川の配置、土・樹皮・苔岩のテクスチャを維持しています。

根元の高さは幹の中心だけでなく、最大 2.1×配置スケールの半径内を複数の円周で採取し、
その最低高度から少し埋めて決めます。幹と樹冠は同じ量だけ下げ、根の先が斜面から浮かないようにしています。

森林の端が空色に抜けないよう、地面を左右 70m・奥行き -100〜28m に拡張し、
奥と側面は最大 7.5m まで緩やかに上がる地形にしています。遠景に樹木 45 本を追加し、
低い葉のビルボード 133 枚を複数の列に重ねています。
葉の背景は既存の樹冠画像を流用するため、新しい画像や高精細樹木モデルは不要です。
幹のある樹木は合計 154 本。背景の低い葉は樹木の詳細度切替とは独立して描画します。

## アセットと調整箇所

形状はこのリポジトリ用の手続き生成です。土・樹皮・苔岩・水面の画像は内蔵の画像生成ツールで作成し、
PNG と生成プロンプトを保存しています。ビルド・再生成・実行時の外部サービスへの接続は不要です。

- `samples/forest/scene.h`: 配置、色、霧、風、光、カメラ。アプリと描画検証で共用。
- `samples/forest/main.cpp`: アセット読み込みとウィンドウ、キー操作。
- `tools/generate_forest_assets.py`: 樹木 3 種と遠景モデルを含む 23 個の GLB の再生成。Python 標準ライブラリのみ。
- `tools/generate_forest_billboards.py`: 樹冠の焼き込みと 24 個のビルボード GLB の生成・検証。
- [billboards/README.md](../assets/samples/forest/billboards/README.md): 再生成手順と制約。
- `assets/samples/forest`: 再生成済みの 47 個の GLB。通常のビルドに Python は不要。
- [textures/README.md](../assets/samples/forest/textures/README.md): 素材画像の由来と生成プロンプト。

```sh
python3 tools/generate_forest_assets.py
python3 tools/generate_forest_assets.py --check
python3 tools/generate_forest_billboards.py --check
```

## 描画検証

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DALLOY3D_BUILD_TESTS=ON
cmake --build build -j 8
ctest --test-dir build -R forest_scene --output-on-failure
```

実際の Metal GPU を使い、全アセットと 3 枚の sRGB テクスチャ・ミップマップの読み込み、
シェーダーのコンパイル、時刻の再現性、
アニメーションと風・光・霧・影それぞれの切替、および水流だけの画像変化・停止・再開を確認します。
木部と葉の変換一致、カメラ前進による詳細度の切替、元の視点へ戻した際の画像一致、遠景画像の切替と MASK 材質も検証します。
水滴の移動・独立切替・停止・再開、10 秒間の粒子数上限・高さ・水路内の位置も検証します。
異なる3視点で近景への集中率と、時刻を止めたままカメラを動かした際の水滴の位置保持も確認します。
根の先端範囲が地形より浮かないことと、正面・見回し時の低い遠景が空色に抜けないことも確認します。
Metal が利用できない環境は終了コード 77 でスキップします。
`build/forest-preview-0.ppm`、`forest-preview-2.ppm`、`forest-preview-no-shafts.ppm` に
比較用の画像を出力し、GPU 時間と CPU の描画登録・エンコード時間も表示します。
水滴を OFF にした場合と、同じ樹冠でビルボードを OFF にした場合の GPU 時間も別途測定します。
`forest-preview-drops-0.ppm`〜`forest-preview-drops-2.ppm` は 0.12 秒間隔の水滴、
`forest-preview-no-drops.ppm` は水滴を消した近景です。
`ALLOY3D_FOREST_CAPTURE_DROPLETS=1` を付けて検証すると、4 秒間・12fps の
`forest-preview-drop-motion-0.ppm`〜`forest-preview-drop-motion-47.ppm` も保存します。
`forest-preview-bark.ppm` と `forest-preview-ground-rock.ppm` には質感確認用の近接画像を出力します。
`forest-preview-water-detail.ppm` は小川の近景、`forest-preview-turned.ppm` は見回した視点、
`forest-preview-no-billboards.ppm` は遠景を 3D にした比較画像です。
`forest-preview-tree-1.ppm`〜`forest-preview-tree-3.ppm` は霧を切った樹木単体の確認画像です。
1000×1000 のオフスクリーン描画なので、実ウィンドウのフレーム時間とは別の測定値です。
