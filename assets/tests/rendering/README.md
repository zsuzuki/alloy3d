# Rendering fixtures

Original, tiny assets generated by `tools/generate_render_fixtures.py` with only
the Python standard library. No external model or image data is used.

- `normals.glb`: triangle with normal (1,1,1), node scale (0.8,1.2,0.6).
- `skinned_normals.glb`: the same triangle, 25%/75% weights on two differently
  scaled joints. Their blended transform equals the normal fixture's transform.
- `opaque_parts.glb`: two colored, overlapping parts.
- `transparent_parts.glb`: the same two parts with 0.5 alpha.
- `textured_parts.glb`: two parts with an embedded 1x1 PNG containing alpha.

Regenerate with `python3 tools/generate_render_fixtures.py` or verify the exact
checked-in bytes with `python3 tools/generate_render_fixtures.py --check`.
