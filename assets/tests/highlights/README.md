# Highlight fixture

`sphere.glb` is an original smooth unit sphere (64 slices, 32 stacks, 3968 triangles),
generated by `tools/generate_highlight_fixture.py`. It has normals and a blue base
color, with no texture, skin, or external assets. Run the generator with `--check`
to verify the checked-in bytes. Used by `alloy3d_highlight_probe` for visual and GPU comparisons.
