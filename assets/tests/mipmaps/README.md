# Mipmap fixtures

Original deterministic GLBs generated by `tools/generate_mipmap_fixtures.py`.
Run with `--check` to verify the checked-in bytes.

- `checker.glb`: opaque unlit 1024×1024 black/white one-texel checker.
- `npot.glb`: opaque unlit 30×18 solid RGB (64,128,192).
- `single.glb`: the same solid color in a 1×1 texture.
- `mask_dense.glb`: 64×64 MASK image, 75% opaque alpha, cutoff 0.5.
- `mask_sparse.glb`: 64×64 MASK image, 25% opaque alpha, cutoff 0.5.

MASK fixtures exercise ordinary alpha averaging; they do not imply alpha-coverage preservation.
