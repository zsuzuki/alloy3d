# 多関節アニメーション検証モデル

外部モデルを使用せず、`tools/generate_animation_fixtures.py` で生成したGLBです。
リポジトリと同じライセンスで利用できます。サンプルビューアにも同梱され、
起動すると既存モデルの後方に3体並んで表示されます。
25関節はWave、100関節はLift、200関節は両クリップのブレンドを再生します。
カメラは展示全体を見渡す位置から開始し、矢印キーまたはゲームパッドの右スティックで
周回できます。Rキーで初期視点に戻ります。WASDは手前のバウンサーを移動します。

| ファイル | スキンの関節数 | 全ノード数 | メッシュ |
| --- | ---: | ---: | --- |
| `rig_25.glb` | 25 | 29 | 5本のストランド |
| `rig_100.glb` | 100 | 104 | 20本のストランド |
| `rig_200.glb` | 200 | 204 | 40本のストランド |

ストランドは5関節の連鎖です。各関節に細長い四角形を配置し、2つの関節に
0.75/0.25のウェイトを設定しています。各モデルは1メッシュ・1スキンです。
親が子より後に格納されるノード順序、平行移動を持つmatrixルート、
アニメーションしないmatrix/TRSノードも含みます。

- `Wave`（2秒）：全関節のZ回転をLINEAR補間。最後のキーは符号を反転した
  同値クォータニオンで、短い経路を選ぶ既存補間の動作を検証します。
- `Lift`（3秒）：全関節の平行移動をSTEP補間、スケールをLINEAR補間。
  Waveと異なる成分をアニメーションさせ、クリップ切替時の姿勢リセットを検証します。

ノード名は意図的に長くし、旧実装の文字列コピーによるヒープ確保も測定対象にしています。
関節数に対する更新コストの比較用であり、200階層の深いリグや人型モデルの
品質評価用ではありません。回転補間の仕様を変更するためのモデルでもありません。

再生成と一致確認（Python標準ライブラリのみ）:

```sh
python3 tools/generate_animation_fixtures.py
python3 tools/generate_animation_fixtures.py --check
```

詳細な計測・検証手順は `docs/animation-performance-ja.md` を参照してください。
